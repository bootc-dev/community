# bootc community

Welcome to the bootc community! This repository is a starting point for
participating in the project and finding its shared community documents.
The bootc project provides transactional, in-place operating system updates
using OCI container images, with related tools for development and deployment.

## Projects

- [bootc](https://github.com/bootc-dev/bootc)
- [bootc-operator](https://github.com/bootc-dev/bootc-operator)
- [bink](https://github.com/bootc-dev/bink)
- [bcvk](https://github.com/bootc-dev/bcvk)

See the [bootc-dev organization](https://github.com/bootc-dev) for other
repositories.

## Communicating

Ask questions and share ideas in [bootc Discussions](https://github.com/bootc-dev/bootc/discussions).
For project-specific bugs and requests, use the relevant repository's issue
tracker.
The project also holds public developer meetings. See [Governance](GOVERNANCE.md#meetings)
for meeting details and browse the [meeting notes](meetings/) for past discussions.

## Governance

The [governance document](GOVERNANCE.md) explains the project's values, roles,
and decision-making process. See [Maintainers](MAINTAINERS.md) for the current
maintainers and community managers. Everyone participating in the project is
expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

For vulnerabilities in the core bootc tool, follow the
[Security Policy](SECURITY.md) to report them privately.

## Contribute

You can improve the community documents in this repository by opening a pull
request. For code contributions, choose the relevant repository above and
follow its contribution guidance. For the core bootc tool, start with the
[contribution guide](https://github.com/bootc-dev/bootc/blob/main/CONTRIBUTING.md). If you use bootc or related technology,
you can add your project to the [Adopters list](ADOPTERS.md).

## Project contributors

Regular contributors can become official Project Contributors. The
[governance document](GOVERNANCE.md#becoming-a-project-contributor) describes
the requirements and how to request this role.
